Atestat Informatica - **TUDOR POP** 

Proiect: **Algoritm pentru determinarea APM**

Prezentare:

  Lucrarea de față prezintă doi algoritmi clasici pentru determinarea **Arborelui Parțial de cost Minim** (APM) într-un graf neorientat ponderat. 
  Arborele Parțial de cost Minim (APM) reprezintă un *subgraf conex* al unui *graf neorientat ponderat*, care include toate nodurile grafului inițial, nu conține cicluri și are proprietatea că suma costurilor muchiilor componente este minimă posibilă. Cu alte cuvinte, dintr-un graf cu n noduri, APM-ul va conține întotdeauna exact **n-1 muchii**, conectând toate nodurile cu costul total cel mai mic.
